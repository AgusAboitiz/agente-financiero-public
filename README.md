# Agente Financiero

Proyecto personal para explorar cómo transformar estados de cuenta y movimientos manuales en un resumen financiero claro, trazable y útil.

La idea es recibir información financiera desde una única entrada, clasificarla con asistencia de IA y generar proyecciones de gastos y cuotas. Los cálculos importantes se mantienen determinísticos y cualquier dato ambiguo requiere revisión humana.

## Principios

- Privacidad primero: no se publican datos financieros, documentos ni credenciales.
- Separación de personas, medios de pago, gastos fijos y cuotas.
- Trazabilidad: cada movimiento debe conservar su origen y poder validarse.
- La IA ayuda a interpretar y explicar; no decide saldos ni modifica información sin aprobación.

El desarrollo se encuentra en una etapa inicial. Este repositorio es sólo una vista pública del concepto; la implementación y la información de prueba permanecen privadas.
